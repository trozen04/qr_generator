# QReviX: QR Code Generator

A simple and fast QR Code generator built using Flutter. Easily convert text or URLs into scannable QR codes with a clean and responsive UI.

## 🔍 Features

- Generate QR codes from text or links  
- Real-time preview as you type  
- Download or share the generated QR code  
- Clean and minimal Flutter UI  
- Responsive design for mobile and tablets

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (latest stable version recommended)  
- IDE: Android Studio, VS Code, or any Flutter-supported environment

### Installation

```bash
git clone https://github.com/trozen04/qr_generator.git
cd qr_generator
flutter pub get
```

### Run the App

```bash
flutter run
```

## 📦 Dependencies

This project uses the following Flutter package:

- [qr_flutter](https://pub.dev/packages/qr_flutter) — To generate QR codes
